# АгроРасчёт

Веб-калькулятор экономики сельскохозяйственной техники. Помогает оценить себестоимость, окупаемость и выбрать между покупкой, арендой и услугами подрядчика.

## Возможности

- расчёт себестоимости часа и гектара;
- годовой денежный поток и срок окупаемости;
- оптимистичный, базовый и стресс-сценарии;
- анализ чувствительности к ключевым параметрам;
- сравнение собственной техники, аренды и подрядчика;
- минимальная загрузка для экономически оправданной покупки;
- предварительная оценка кредита и лизинга;
- сравнение моделей и печатный отчёт;
- локальное сохранение введённых параметров.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска приложение будет доступно по адресу, указанному Vite, обычно `http://localhost:5173`.

## Проверка и сборка

```bash
npm run test:run
npm run build
```

Готовая production-сборка создаётся в каталоге `dist`.

## Методика

Амортизация входит в бухгалтерскую себестоимость, но не вычитается повторно из денежного потока.

```text
Себестоимость часа = топливо + амортизация/ч + сервис/ч + прочие расходы/ч

Эффективная производительность = производительность × использование рабочего времени

Себестоимость гектара = себестоимость часа / эффективная производительность

Денежный поток = площадь × (экономия + дополнительный доход)/га
                  − топливо − сервис − прочие расходы

Простой срок окупаемости = стоимость покупки / годовой денежный поток

Минимальная площадь = постоянные затраты
                      / (тариф подрядчика − топливо на гектар)
```

Расчёты являются предварительной оценкой. Цены, производительность, условия финансирования и эксплуатационные расходы следует заменять фактическими данными хозяйства.
